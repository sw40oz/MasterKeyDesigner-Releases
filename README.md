# MasterKey Designer releases

Installers for **MasterKey Designer**, a Windows app for designing master key systems.

This repository holds installers only. There is no source code here.

## Download

**[Download MasterKey Designer 2.3.3 for Windows](https://github.com/sw40oz/MasterKeyDesigner-Releases/raw/main/MasterKeyDesigner-Setup-2.3.3.exe)**

1. Run the downloaded file.
2. If Windows says it protected your PC, click **More info**, then **Run anyway**. The installer isn't code-signed yet.
3. Jobs and settings from an earlier version are kept.

Fingerprint (SHA-256), to check the download: `f2db16790b27b0dd58ea66f1fd86d29a3e49647849df82b963365c44db4b47d5`

Older versions are under **Releases** (on the right). Every installer has a matching `.sha256` file.
